# Web2zip
Script web2zip, clone web lewat aplikasi termux !

<details open><summary><code>Perintah Script?</code></summary>

```php
$ git clone https://github.com/Sxp-ID/web2zip
$ cd web2zip
$ make install
$ ./main

Atau bisa juga run script nya dg ketik perintah
$ make run
```
